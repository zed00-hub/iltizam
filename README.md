## 🌟 الميزات الجوهرية للتطبيق

### 1. 🎯 أنواع العادات الأربعة المتكاملة
- **عادات نعم/لا مع وسوم نوعية مخصصة:** مثل *صلاة الفجر* مع وسوم تفصيلية (*في المسجد، مع تكبيرة الإحرام، في البيت، قضاء*).
- **عادات دورية وأسبوعية:** مثل *التمرين الرياضي 4 أيام في الأسبوع*، مع احتساب السلسلة على مستوى الأسبوع المكتمل وليس مجرد الأيام المنفردة.
- **عادات كمية ورقمية:** مثل *ورد القرآن الكريم (20 صفحة)* أو *شرب الماء (3 لترات)* مع عدّاد فوري وسريع.
- **عادات زمنية وتركيز:** مثل *جلسات العمل العميق أو القراءة* بمؤقت بومودورو وساعة إيقاف تفاعلية مدمجة.

### 2. 🧠 محرك السلاسل وقوة العادة (Streak & Habit Strength Engine)
- **مؤشر قوة العادة (Habit Strength %):** خوارزمية أسية مستوحاة من معادلات الذاكرة والانحدار التراكمي؛ لا ينهار جهد 60 يوماً من الالتزام لمجرد تعثر عارض في يوم واحد.
- **حساب الأيام المستحقة فقط:** السلسلة تحسب وفق الأيام المجدولة للعادة (مثلاً عادة تعمل فقط في عطلة نهاية الأسبوع لا تنكسر خلال أيام العمل).
- **تجميد السلسلة (Streak Freeze):** لحماية السلسلة في الأيام الاستثنائية والظروف القهرية دون احتسابها كيوم إنجاز وهمي.
- **قاعدة اليومين (Never Miss Twice):** تنبيه فوري ونظام حماية مضاعف عند تفويت يوم، لمنع الانقطاع لمرتين متتاليتين.

### 3. 🚀 تجربة مستخدم جديد نظيفة 100% (First-Time User Experience)
- **قاعدة بيانات مستقلة وفارغة:** يبدأ كل مستخدم جديد بقاعدة بيانات نظيفة تماماً تخلو من أي بيانات تجريبية أو وهمية.
- **شاشة ترحيب وإعداد أولي (Onboarding):** إعداد اسم المستخدم ومواعيد الاستيقاظ والنوم المفضلة لتخصيص التجربة (مع إمكانية التخطي الفوري).
- **كتالوج قوالب العادات (Templates Catalog):** مكتبة قوالب جاهزة ومصنفة (*إيمانيات، صحة ورياضة، تطوير وتعلّم، إنتاجية وتركيز*) يمكن إضافتها بنقرة واحدة عند الحاجة.

### 4. 📊 تحليلات ورسوم بيانية ديناميكية
- **شبكة نشاط سنوية (Activity Heatmap):** شبكة تشبه مساهمات GitHub لعرض كثافة الالتزام السنوي لكل عادة أو لكافة العادات.
- **توزيع أيام الأسبوع والساعات:** تحليل دقيق لأكثر الأيام والساعات التزاماً لتحديد أوقات ذروة الإنتاجية.
- **مؤشرات عامة:** نسبة الإنجاز اليومي، متوسط الالتزام، أفضل سلسلة، وأطول فترة انضباط.

### 5. 🏆 التلعيب والأوسمة السلوكية المحايدة (Gamification)
- نظام نقاط خبرة (XP) ومستويات تصاعدية من (مبتدئ) حتى الرتبة العليا: **دبابة التزام** 🛡️.
- أوسمة وشارات استحقاق مبنية على مؤشرات سلوكية رياضية حقيقية (*خطوة البداية، 3 أيام، أسبوع ذهبي، سلسلة 30 يوماً، مئوية الالتزام، طائر الصباح، بطل التركيز*).

### 6. 💾 النسخ الاحتياطي والاستعادة الذكية (Offline-First & Smart Restore)
- **تصدير كامل:** حفظ كافة العادات والسجلات وتفضيلات المستخدم في ملف `JSON` محلي مشفر ونظيف.
- **معاينة مسبقة قبل الاستيراد:** فحص الملف والتحقق من سلامة البنية وإصدار النسخة وعرض إحصائيات ما يحتويه الملف للمستخدم.
- **وضعان للاستعادة:**
  - **الدمج الذكي (Smart Merge):** دمج البيانات الجديدة مع البيانات الحالية ومنع تكرار السجلات نهائياً.
  - **الاستبدال الشامل (Full Replace):** مسح البيانات السابقة واستبدالها بالكامل مع طلب تأكيد مسبق.
- **الخصوصية التامة:** التطبيق يعمل محلياً بالكامل (Offline-First) ولا يتم إرسال أي بايت من بياناتك إلى أي خادم خارجي.

## 🎨 الهوية البصرية (Design Language)

- **OLED Dark Theme:** خلفيات سوداء عميقة (`#0B0F17`) توفر استهلاك البطارية على شاشات AMOLED.
- **ألوان الانضباط والقوة:** لمسات باللون الزمردي الصامد (`#10B981`) والذهبي التنافسي (`#F59E0B`) والياقوتي الحاسم (`#EF4444`).
- **دعم كامل للغة العربية (RTL):** خط **Cairo** المدمج بتناسق بصري مثالي مع كافة الشاشات والأيقونات.

## 🏗️ البنية المعمارية للمشروع (Clean Architecture)

```text
lib/
├── core/
│   ├── constants/             # لوحة الألوان، الخطوط، وثوابت النظام
│   ├── theme/                 # ثيم Dark OLED و Light وثيمات الواجهات
│   └── utils/                 # دوال مساعدة للتواريخ وتوليد الهزاز اللمسي (Haptics)
├── features/
│   └── habits/
│       ├── domain/
│       │   ├── models/        # النماذج: Habit, Record, UserProfile, HabitTemplate, Level
│       │   └── services/      # المحركات: StreakEngine, HabitStrength, GamificationEngine
│       ├── data/              # التخزين المحلي: LocalStorageService, HabitRepository
│       └── presentation/
│           ├── providers/     # إدارة الحالة عبر Riverpod Notifiers (Profile, Habits, Analytics)
│           ├── widgets/       # بطاقات العادات، مؤقت التركيز، شبكة النشاط، حلقة التقدم اليومي
│           └── screens/       # الشاشات: Onboarding, Dashboard, HabitDetail, Analytics, Settings
├── main_navigation_screen.dart # شريط التنقل السفلي الفاخر
└── main.dart                  # نقطة البداية والتحقق من حالة الـ Onboarding
```

## ⚙️ التشغيل المحلي والتطوير

### المتطلبات الأساسية:
- Flutter SDK (نسخة 3.24+ فما فوق)
- Dart SDK (نسخة 3.5+ فما فوق)
- Android Studio أو VS Code

### خطوات التشغيل:
```bash
# 1. استنساخ المستودع
git clone https://github.com/zed00-hub/iltizam.git
cd iltizam

# 2. تثبيت الحزم
flutter pub get

# 3. تشغيل التطبيق (على متصفح Chrome أو جهاز متصل)
flutter run -d chrome
# أو لتشغيله على محاكي/هاتف أندرويد:
flutter run

# 4. بناء نسخة إنتاجية للـ APK:
flutter build apk --release --no-tree-shake-icons
```
